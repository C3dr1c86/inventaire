## EN CAS DE PROBLÈME PERSISTANT

Si après Ctrl+Shift+R vous voyez encore des erreurs :

1. **Vider complètement le cache navigateur** :
   - Chrome : Paramètres → Confidentialité → Effacer données navigation
   - Ou utilisez la **navigation privée**

2. **Vérifier les logs backend** :
   ```bash
   sudo docker logs inventaire-backend | grep "307\|redirect"
   ```
   Vous ne devriez **plus voir de 307** !

3. **Vérifier env-config.js** :
   ```bash
   sudo docker exec inventaire-frontend cat /usr/share/nginx/html/env-config.js
   ```
   Doit afficher : `VITE_API_URL: "/api"`
