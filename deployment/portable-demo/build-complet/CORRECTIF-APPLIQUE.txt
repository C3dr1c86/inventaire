PROBLEME DETECTE
================

Lors du premier test de démarrage :

Symptôme :
  [3/3] Demarrage frontend...
  Le chemin d'accès spécifié est introuvable.
  Le chemin d'accès spécifié est introuvable.

Cause :
  Le script "Lancer Inventaire.bat" cherchait un dossier "frontend\dist"
  qui n'existait pas. Les fichiers du frontend sont directement dans
  le dossier "frontend\" (pas de sous-dossier dist).


CORRECTION APPLIQUEE
=====================

Fichier modifié : Lancer Inventaire.bat

Ligne 27-29 AVANT :
  cd frontend\dist
  start /B cmd /c "..\..\python\python.exe -m http.server 5173 > ..\..\logs\frontend.log 2>&1"
  cd ..\..

Ligne 27-29 APRES :
  cd frontend
  start /B cmd /c "..\python\python.exe -m http.server 5173 > ..\logs\frontend.log 2>&1"
  cd ..
