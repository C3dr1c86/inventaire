PRESENTATION
============

Cette version est 100% portable et ne nécessite AUCUNE installation.
Elle fonctionne sur n'importe quel PC Windows (7, 10, 11) même sans Python installé.

Contenu du package :
- Python 3.11.8 embarqué avec toutes les dépendances
- Backend FastAPI avec base de données SQLite
- Frontend React (interface web)
- Base de données de démonstration avec 50+ articles

Taille totale : ~150 MB


DEMARRAGE RAPIDE
================

1. Copiez le dossier complet sur votre PC ou clé USB
2. Double-cliquez sur "Lancer Inventaire.bat"
3. Attendez 20 secondes que l'application démarre
4. Le navigateur s'ouvre automatiquement sur http://localhost:5173
5. Connectez-vous avec : admin / admin


UTILISATION
===========

Démarrage :
-----------
Double-cliquez sur "Lancer Inventaire.bat"

Une fenêtre noire s'ouvre et affiche :
  [1/3] Démarrage backend...
  [2/3] Attente backend (15 secondes)...
  [3/3] Démarrage frontend...
  APPLICATION PRETE !

Le navigateur s'ouvre automatiquement.

IMPORTANT : Ne fermez PAS la fenêtre noire pendant l'utilisation !
             C'est le serveur qui fait tourner l'application.


Arrêt :
-------
Double-cliquez sur "Arreter Inventaire.bat"
Cela fermera proprement tous les processus.


Identifiants :
--------------
Login : admin
Mot de passe : admin


FONCTIONNALITES
===============

L'application permet de gérer :
- Articles avec catégories hiérarchiques (ex: Matériaux > Bois)
- Stocks avec alertes de seuil minimum
- Mouvements d'entrée/sortie avec historique
- Tags colorés pour organiser les articles
- Recherche et filtres avancés
- Exports CSV et PDF
- Dashboard avec statistiques


CATEGORIES HIERARCHIQUES (v1.1.0)
==================================

Vous pouvez créer des catégories principales et des sous-catégories :

Exemples de structure :
- Matériaux > Bois, Métal, Plastique
- Consommables > Quincaillerie, Colles, Électricité
- Outillage > Manuel, Électrique, Mesure
- Pièces Détachées > Impression 3D, Électronique
- Projets > Menuiserie, Électricité, Plomberie

Pour créer une sous-catégorie :
1. Aller dans Catégories
2. Créer nouvelle catégorie
3. Sélectionner une "Catégorie parente"

PORTABILITE
===========

Clé USB :
---------
Copiez le dossier complet sur une clé USB.
Sur n'importe quel PC, lancez "Lancer Inventaire.bat"
Les données sont sauvegardées dans le dossier.

Sauvegarde :
------------
Pour sauvegarder vos données, copiez simplement :
  backend/database/inventaire.db

Restauration :
--------------
Remplacez le fichier inventaire.db par votre sauvegarde.


DEPANNAGE
=========

Le navigateur ne s'ouvre pas :
-------------------------------
Ouvrez manuellement votre navigateur et allez sur :
http://localhost:5173


Erreur "Port déjà utilisé" :
-----------------------------
Un autre programme utilise le port 8000 ou 5173.
Fermez les autres applications et réessayez.


Erreur de connexion :
---------------------
Attendez 30 secondes au lieu de 15.
Le premier démarrage peut être plus long.


L'application ne démarre pas :
-------------------------------
1. Vérifiez que vous avez bien double-cliqué sur "Lancer Inventaire.bat"
2. Consultez les logs dans logs/backend.log
3. Vérifiez que le dossier n'est pas en lecture seule


Antivirus bloque le lancement :
--------------------------------
Certains antivirus bloquent Python.
Ajoutez le dossier aux exceptions de l'antivirus.


CARACTERISTIQUES TECHNIQUES
============================

Backend :
- FastAPI (API REST)
- SQLAlchemy ORM
- SQLite database
- Python 3.11.8 embedded

Frontend :
- React 18
- Vite build tool
- React Query pour le cache
- Interface responsive

Ports utilisés :
- Backend : 8000
- Frontend : 5173

Aucune connexion internet requise.


CONFIGURATION AVANCEE
=====================

Pour modifier le port du backend :
Éditez backend/.env.portable et changez API_PORT

Pour modifier le port du frontend :
Éditez "Lancer Inventaire.bat" ligne 28 :
  python\python.exe -m http.server NOUVEAU_PORT
