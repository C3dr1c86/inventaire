COMMENT DEPLOYER
================

Option 1 : Clé USB
------------------
1. Extraire inventaire-portable-complet-v1.1.0.zip sur la clé USB
2. Sur n'importe quel PC Windows, double-cliquer sur "Lancer Inventaire.bat"
3. Attendre 20 secondes
4. Le navigateur s'ouvre automatiquement
5. Login : admin / admin

Option 2 : PC personnel
-----------------------
1. Extraire le ZIP n'importe où (Bureau, Documents, etc.)
2. Double-cliquer sur "Lancer Inventaire.bat"
3. C'est tout !

Option 3 : Partage réseau
--------------------------
1. Extraire le ZIP sur un lecteur réseau partagé
2. Chaque utilisateur lance "Lancer Inventaire.bat" depuis son PC
3. ATTENTION : Chaque utilisateur aura sa propre instance locale
   (pour multi-utilisateur, attendre v1.7.0)

COMPARAISON AVEC VERSION DOCKER
================================

Version Portable Complète :
+ Aucune installation
+ Fonctionne partout
+ Facile à distribuer
+ Idéal pour démos et clés USB
- Plus gros (150 MB)
- Un seul utilisateur

Version Docker :
+ Plus léger (images réutilisables)
+ Multi-utilisateur possible
+ Meilleure isolation
- Nécessite Docker installé
- Plus complexe à configurer


NOTES TECHNIQUES
================

Python Embedded :
-----------------
Nous utilisons Python 3.11.8 Windows embeddable package.
Configuration dans python/python311._pth pour activer site-packages.

Installation pip :
------------------
pip installé manuellement via get-pip.py
Toutes les dépendances installées dans python/Lib/site-packages/

Base de données :
-----------------
SQLite avec données de démonstration créées par scripts/create-demo-db.py

Frontend :
----------
Build Vite servi via http.server de Python
Pas besoin de Node.js au runtime
